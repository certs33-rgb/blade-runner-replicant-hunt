BLADE RUNNER // REPLICANT HUNT
==============================
A neon cyberpunk action shooter. Single-file HTML5 canvas game.

RUN IT
------
Option A (easiest): just open index.html in any modern browser.
Option B (recommended): serve the folder so assets load cleanly:
    python3 -m http.server 8000
    -> http://127.0.0.1:8000/

CONTROLS
--------
Arrows / WASD  ... move
Z / Space      ... pulse blade thrust
M              ... mute
P              ... pause
Touch: on-screen joysticks appear on mobile.

FILES
-----
index.html     the entire game
art-title.webp title screen artwork
art-win.webp   win screen artwork
icon.png       favicon / app icon
